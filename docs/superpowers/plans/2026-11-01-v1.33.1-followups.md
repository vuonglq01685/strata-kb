- Version `1.33.1`; CHANGELOG heading `## 1.33.1 — 2026-11-01`.
- No change to `_l3check.yaml` / `_l3fix.yaml` schemas.
- Reject messages keep the existing `<check>: <detail>` form; the link reject stays `links: <target>`.
- Docling message unchanged: `Docling is not installed. Run: pip install "strata-kb[ingest]"`.
- Task 3 is a pure move: no test outside the new import lines may change.
- Run `uv run pytest -q` (whole suite) and `uv run ruff check . && uv run ruff format --check .` before each commit.

## Review Focus

1. Image repeated 3× in the L3, draft keeps 1 → passes (Task 4 test `test_triple_image_keeps_one_passes`).
2. Draft removes every copy of a repeated image → rejects `links: <target>` (Task 4 test `test_repeated_image_all_copies_removed_rejected`).
3. Draft keeps both copies but swaps their order with another image → rejects (Task 4 test `test_repeated_image_reorder_rejected`).
4. AI-fixed section with no `_l3check` finding → report prints only the fix line, count unchanged (Task 1 test `test_report_ai_fix_without_findings_prints_line_only`).
5. `kb l3 lint` without docling → exit 1, message, no traceback (Task 2 test `test_cli_lint_without_docling_no_traceback`).

Algorithm (the tests do not pin it alone):

```
old, new = _link_targets(t.run), _link_targets(draft)

  if old[i] == new[j]: advance both

```
