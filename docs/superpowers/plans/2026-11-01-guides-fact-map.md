# Guides rewrite — fact map and security inventory

Baseline: strata-kb 1.34.0 (`pyproject.toml:3`). Branch `claude/cross-platform-pdf`.
Built from the code only. README, the old guides and the quickstarts were used as leads and
checked against code; where they disagree with code the finding is in `## Follow-ups`.

**How to read this.** Paths are under `src/strata_kb/` unless they start with `docs/`, `README.md`
or `tests/`. `T/` = `src/strata_kb/templates/init/`. A scaffold file name `<x>` has up to four
wrappers: `T/claude-skill-<x>.md`, `T/claude-command-<x>.md`, `T/copilot-<x>.prompt.md`,
`T/cursor-<x>.md` (shared bodies live in `T/bodies/<x>.md`, pulled in by the include line,
`initcmd.py:172-189`). Tasks 3-8 write from this map. A cite is `file:line`.

**Slash-command caveats (the "works in all three tools" sentence needs these exceptions).**
- `/kb-summarize` has **no Copilot prompt**. Copilot gets `.github/instructions/kb-summarize.instructions.md`
  (`applyTo: ".kb/**"`, `T/copilot-kb-summarize.instructions.md:1-3`), mapped at `initcmd.py:38,307`.
  Claude Code and Cursor have the command (`T/cursor-kb-summarize.md`) plus a Cursor rule `.cursor/rules/kb-summarize.mdc`.
- `/kb-ingest` and `/kb-publish` exist for Claude Code only as **skills** (`.claude/skills/<n>/SKILL.md`),
  with no `.claude/commands/` file (`initcmd.py:303-305` comment; computed from `template_map`). The skill
  description says "when the user invokes /kb-ingest", so the slash form is still right. Copilot and Cursor have the wrapper.
- `/kb-l3-fix` is useful only while `l3_fix.enabled` is true (`T/claude-command-kb-l3-fix.md:2`).

Shared `kb init` behaviour (all kinds), `cli.py:329-475`, `initcmd.py:792-878`:
- Kind resolution: kind already in `.kb/config.yaml` wins; `--kind` that conflicts exits 1; else `--kind`; else prompt on a TTY; else exit 1 (`cli.py:209-247`).
- Re-running `kb init` creates missing files and refreshes changed scaffold files. Protected (skipped unless `--force`): `.kb/index.yaml`, `.kb/config.yaml`, `.claude/settings.json` (`initcmd.py:351-353`; skip hint `cli.py:403`).
- `.gitignore` is merge-only, even with `--force` (`initcmd.py:358-392`). `.kb/config.yaml` gets `kind:` appended when missing (`initcmd.py:500-514,823`).
- `.claude/settings.json` (ba, dev only) is **merged**, not skipped: your entries stay, template entries are added; `--force` replaces; an invalid JSON file is left alone with a note (`initcmd.py:680-768`).
- Prints "Next steps" per kind and the quickstart name: `QUICKSTART.md` (hub, child), `QUICKSTART-BA.md`, `QUICKSTART-DEV.md` (`cli.py:414-475`).
- `kb doctor` later refreshes only the agent files (`.claude/skills/`, `.claude/commands/`, `.github/prompts/`, `.cursor/commands/`, `docs/pr-review-rubric.md`) via `refresh_agent_files` (`initcmd.py:772-789`).
